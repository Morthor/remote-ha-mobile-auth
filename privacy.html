Remote HA Mobile

Privacy policy

Last updated: 11 October 2026

Remote HA Mobile is a direct client for the Home Assistant server chosen by the user. It has no Remote HA account, advertising SDK, telemetry, crash-reporting service, or usage analytics.

Data stored on the phone

  • Home Assistant local and remote addresses, trusted Wi-Fi names, routing mode, and dashboard customization are stored in Android app preferences.
  • Home Assistant credentials and the optional editing PIN are stored using Android secure storage and are not displayed again by the app.
  • Configuration exports contain routing and dashboard settings, but never Home Assistant credentials or the editing PIN.
  • Android backups are disabled for the application.

Data used while the app runs

  • Home Assistant entity state, registry, calendar, weather, and camera data are requested directly from the server selected by the user. They are used to render the dashboard and are not forwarded to the developer or another Remote HA service.
  • Wi-Fi name access is used only to choose between configured local and remote addresses. Android may require location permission and enabled location services to reveal that name. When it is unavailable, automatic routing uses the configured remote address.
  • Optional local doorbell notifications are generated from Home Assistant events while the app process is running. Reliable delivery after Android closes this app can use the separately installed official Home Assistant Companion app. Remote HA Mobile does not run a push server or receive that notification's contents.

User control and deletion

Connection settings and dashboard configuration can be exported without credentials. Uninstalling the app clears its preferences and secure storage under normal Android application-management behavior. Users can also log out in the app or revoke its Home Assistant token from their Home Assistant profile. Because Remote HA Mobile has no developer-held account or cloud database, there is no separate developer-side account or personal-data record to delete.

Support

Questions about this policy can be submitted through the support page. Do not include credentials, private addresses, Wi-Fi names, entity identifiers, household addresses, or camera imagery in a public report.
