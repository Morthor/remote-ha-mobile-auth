Remote HA Mobile

Support

Remote HA Mobile is an independent, unofficial Home Assistant client. For setup help or a reproducible app defect, open a support request .

Before reporting a problem

  1. Confirm that the official Home Assistant app or a browser can reach the same address from the same network.
  2. In Remote HA Mobile, open Settings and export the privacy-safe support diagnostics bundle.
  3. Include the app version, Android version and device class, Home Assistant permission level, the route shown by the app, any network transition, reproducibility, expected and actual results, and daily control impact.

Never post an access token, password, private Home Assistant address, Wi-Fi name, entity identifier, camera image, or household address. The diagnostics export is designed to omit those values, but review every attachment before uploading it.

Home Assistant server, network, VPN, Nabu Casa, and third-party integration support remains with the relevant provider.
